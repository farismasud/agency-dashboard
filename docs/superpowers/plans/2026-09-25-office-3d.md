# Office 3D View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat SVG/sprite office visualization with a real three.js 3D scene: low-poly GLB character models, primitive-geometry furniture/room, fixed camera.

**Architecture:** `@react-three/fiber` + `@react-three/drei` render a `<Canvas>` inside `web/components/Office3D/`. Character position/status still comes from the same `agents` prop as before; movement between desk and break-area is animated per-frame (`useFrame` lerp) instead of via CSS transitions.

**Tech Stack:** three, @react-three/fiber, @react-three/drei (new deps). Kenney "Mini Characters" GLB models (CC0).

**Spec:** `docs/superpowers/specs/2026-09-25-office-3d-design.md`

## Global Constraints

- Library: `@react-three/fiber` + `@react-three/drei`, not vanilla three.js.
- Characters: Kenney "Mini Characters" GLB (CC0) — one male, one female base model, cloned per agent via `drei`'s `<Clone>`.
- Furniture/room: three.js primitive geometry only (`BoxGeometry`, `CylinderGeometry`, `PlaneGeometry`, `ConeGeometry`) — no external furniture asset is sourced.
- Camera: fixed `PerspectiveCamera`, no `OrbitControls` this iteration.
- No skeletal animation — movement is a per-frame position lerp (`useFrame`), not embedded GLB animation clips.
- `Office`'s external prop contract is unchanged: `{ agents: Record<string, AgentState> }` from `web/lib/types.ts`. `web/app/kerja/page.tsx`'s import of `Office` must keep working.
- No frontend test framework exists in this project — `tsc --noEmit` and `npm run build` are the only automated checks available. Visual correctness of the WebGL scene cannot be verified by the implementer (no browser tool in this environment) and depends entirely on the user reviewing a live screenshot after each meaningful visual change — say so plainly rather than claiming a look was verified.
- Deviation from the spec's literal wording, decided here for robustness (see Task 4): role color differentiation is done with a small colored floor ring under each character, not by overriding the cloned GLTF mesh's material color — the spec's stated intent ("role color differentiation... at runtime, not by swapping models") is preserved, but overriding an unknown, un-inspected GLB's internal material/node names by name is fragile and unverifiable without a browser. The male/female base-model-per-role assignment from the spec is kept as-is.

## Review Focus

- **GLB fails to load** (network hiccup, wrong path) — the page should show a fallback colored box for that character, not crash the whole `/kerja` route. (Task 4.)
- **Old sprite assets left referenced somewhere after deletion** — a stale `import`/`<img src="/office/...">` should fail the build loudly, not silently render a broken image. (Task 6, verified via `npm run build`.)
- **three.js/Canvas touching `window`/`document` during Next.js's server render** — must be checked by actually running `npm run build` (which performs a production server-render pass), not just `tsc --noEmit` (which only checks types, not runtime behavior). (Task 6.)
- **An agent with an unexpected `subagent_type`** (not `pm`/`analyst`/`dev`/`qa` — e.g. a future new agent role) — desk-position and break-slot lookups must fall back to a safe default position instead of crashing on an undefined index. (Task 5.)
- **Agent status flapping rapidly** (`working` → `idle` → `working` faster than the lerp finishes) — the `useFrame` lerp target must simply be reassigned to the new destination without erroring or visually snapping/glitching; it's read fresh every frame, not cached at transition start. (Task 4.)

- [ ] **Step 1: Write `web/components/Office3D/CharacterModel.tsx`**

```tsx
"use client";

import { Suspense, useRef } from "react";
import { useFrame } from "@react-three/fiber";
import { Clone, Html, useGLTF } from "@react-three/drei";
import * as THREE from "three";
import type { AgentState } from "@/lib/types";
import {
  ROLE_SPRITE,
  ROLE_RING_COLOR,
  ROLE_LABEL,
  DESK_POS,
  BREAK_SLOTS,
  DEFAULT_POS,
  DEFAULT_SPRITE,
  DEFAULT_RING_COLOR,
  DEFAULT_LABEL,
} from "./layout";

const MODEL_URLS = {
  male: "/office3d/characters/male.glb",
  female: "/office3d/characters/female.glb",
};

function CharacterMesh({ sprite }: { sprite: "male" | "female" }) {
  const { scene } = useGLTF(MODEL_URLS[sprite]);
  return <Clone object={scene} scale={0.9} />;
}

function CharacterFallback() {
  return (
    <mesh position={[0, 0.5, 0]}>
      <boxGeometry args={[0.5, 1, 0.3]} />
      <meshStandardMaterial color="#999999" />
    </mesh>
  );
}

export function CharacterModel({
  agent,
  breakSlotIndex,
}: {
  agent: AgentState;
  breakSlotIndex: number;
}) {
  const groupRef = useRef<THREE.Group>(null);

  const sprite = ROLE_SPRITE[agent.subagent_type] ?? DEFAULT_SPRITE;
  const ringColor = ROLE_RING_COLOR[agent.subagent_type] ?? DEFAULT_RING_COLOR;
  const roleLabel = ROLE_LABEL[agent.subagent_type] ?? DEFAULT_LABEL;
  const working = agent.status === "working";

  useFrame((_, delta) => {
    if (!groupRef.current) return;

    // Read the target fresh every frame - if `agent` changes mid-transition
    // (rapid working/idle flapping), the lerp simply redirects toward the
    // new target from wherever the character currently is, no snapping.
    const [targetX, targetZ] = working
      ? DESK_POS[agent.subagent_type] ?? DEFAULT_POS
      : BREAK_SLOTS[breakSlotIndex % BREAK_SLOTS.length];

    const lerpFactor = Math.min(1, delta * 2);
    groupRef.current.position.x = THREE.MathUtils.lerp(groupRef.current.position.x, targetX, lerpFactor);
    groupRef.current.position.z = THREE.MathUtils.lerp(groupRef.current.position.z, targetZ, lerpFactor);

    if (working) {
      groupRef.current.position.y = Math.sin(performance.now() / 400) * 0.05;
    } else {
      groupRef.current.position.y = THREE.MathUtils.lerp(groupRef.current.position.y, 0, lerpFactor);
    }
  });

  return (
    <group ref={groupRef}>
      <mesh rotation={[-Math.PI / 2, 0, 0]} position={[0, 0.01, 0]}>
        <circleGeometry args={[0.5, 24]} />
        <meshStandardMaterial color={ringColor} />
      </mesh>

      <Suspense fallback={<CharacterFallback />}>
        <CharacterMesh sprite={sprite} />
      </Suspense>

      <Html position={[0, 1.9, 0]} center distanceFactor={10}>
        <div className="flex flex-col items-center pointer-events-none select-none">
          {working && (
            <div className="mb-1 max-w-[140px] rounded bg-white/95 px-2 py-1 text-[11px] text-neutral-800 shadow truncate border border-neutral-200">
              {agent.last_action || "Kerja..."}
            </div>
          )}
          <div className="text-[10px] font-medium text-neutral-700 bg-white/80 px-1 rounded">
            {agent.display_name} · {roleLabel}
          </div>
          {!working && <div className="text-[10px] text-neutral-500">☕ Istirahat</div>}
        </div>
      </Html>
    </group>
  );
}
```

```typescript
export function supportsWebGL(): boolean {
  try {
    const canvas = document.createElement("canvas");
    return !!(canvas.getContext("webgl") || canvas.getContext("experimental-webgl"));
  } catch {
    return false;
  }
}
```

- [ ] **Step 2: Write `web/components/Office3D/Office.tsx`**

```tsx
"use client";

import { useEffect, useState } from "react";
import type { AgentState } from "@/lib/types";
import { Scene } from "./Scene";
import { AllDesks } from "./DeskProp";
import { CharacterModel } from "./CharacterModel";
import { supportsWebGL } from "./supportsWebGL";

export function Office({ agents }: { agents: Record<string, AgentState> }) {
  const [webglOk, setWebglOk] = useState<boolean | null>(null);

  useEffect(() => {
    setWebglOk(supportsWebGL());
  }, []);

  const entries = Object.values(agents);
  let idleCount = 0;

  if (webglOk === false) {
    return (
      <div className="rounded-lg border border-amber-200 h-[440px] flex items-center justify-center text-neutral-500 text-sm p-4 text-center">
        3D view tidak didukung di browser ini.
      </div>
    );
  }

  if (webglOk === null) {
    // Still checking (first client render tick) - render nothing rather
    // than flash the 3D scene then immediately swap to the fallback.
    return <div className="rounded-lg border border-amber-200 h-[440px]" />;
  }

  return (
    <div className="rounded-lg border border-amber-200 overflow-hidden h-[440px]">
      <Scene>
        <AllDesks />
        {entries.map((agent) => {
          const isIdle = agent.status !== "working";
          const breakSlotIndex = isIdle ? idleCount++ : 0;
          return (
            <CharacterModel key={agent.subagent_type} agent={agent} breakSlotIndex={breakSlotIndex} />
          );
        })}
      </Scene>
    </div>
  );
}
```

(The `idleCount++` pattern assigns each idle agent a distinct, stable-for-the-render break slot; `breakSlotIndex` doesn't need to be perfectly stable across renders since `CharacterModel` re-reads it fresh each frame via `useFrame` and it only affects which of the 4 fixed slots an idle character eases toward — a brief slot reassignment on a re-render at worst causes one idle character to drift to a different slot, not a crash. An agent with a `subagent_type` outside `pm`/`analyst`/`dev`/`qa` still renders correctly: `CharacterModel` itself falls back to `DEFAULT_POS`/`DEFAULT_SPRITE`/etc. internally, per Task 4.)
